# TucanStore
Esse não apenas um site e sim um protótipo de e-commerce que pode ser ajustado para qualquer
comercio que deseja vender online.

## Escopo do projeto
- **Catálogo de Produtos** → Exibição dinâmica de cards com imagens, títulos, descrições e preços formatados em Real (BRL).
- **Busca de Produtos** → Barra de pesquisa em tempo real com *debounce* para encontrar itens diretamente no catálogo da API pelo nome.
- **Filtros por Categoria** → O usuário pode filtrar os produtos por categorias disponíveis na loja.
- **Carrinho de Compras** → Adição e remoção de produtos no carrinho, controle de quantidades e cálculo automático do valor total.
- **Integração com API Pública** → Consumo assíncrono de dados reais de produtos via DummyJSON API utilizando `Fetch API` e `async/await`.

### Tecnologias utilizadas
#### Frontend
- **HTML5, CSS3 e JavaScript (ES6+)** → Estrutura semântica, estilização customizada e lógica da aplicação.
- **Bootstrap 5** → Grid responsivo, componentes de interface (cards, navbar, modais/offcanvas) e utilitários.
- **Bootstrap Icons / Font Awesome** → Ícones para o carrinho, busca e elementos de navegação.

#### Integrações
- **DummyJSON API** -> Estrutura semântica, estilação customizada e lógica da aplicação.

#### Outras Ferramentas
- **Git & GitHub** → Controle de versão e hospedagem do repositório.

### Objetivos
- Criar uma vitrine virtual funcional que permita buscar, visualizar e adicionar produtos ao carrinho de compras.
- Praticar o consumo de APIs externas de forma assíncrona, aplicando tratamento de erros e otimização de requisições.
- Aplicar boas práticas de organização de código front-end, responsividade com Bootstrap 5 e versionamento com Git.

### Motivo do Projeto
O projeto nasceu do interesse em explorar na prática os conceitos fundamentais de comércio eletrônico no front-end — desde a requisição de dados externos até a atualização dinâmica da interface e gerenciamento de estado do carrinho.
